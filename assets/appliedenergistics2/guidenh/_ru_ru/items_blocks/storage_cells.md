Ячейки хранения — один из основных способов хранения в Applied Energistics 2. Их можно устанавливать в <ItemLink id="appliedenergistics2:tile.BlockDrive" /> или <ItemLink id="appliedenergistics2:tile.BlockChest" />.

См. раздел [Байты и типы](../ae2-mechanics/bytes-and-types.md) для получения информации об их ёмкости в байтах и типах.

Если ячейка хранения пуста, возьмите её в руку и нажмите Shift + правый клик, чтобы извлечь компонент хранения из корпуса.

## Разбиение на разделы

Ячейки можно отфильтровать, чтобы они принимали только конкретные предметы, аналогично фильтрам в <ItemLink id="appliedenergistics2:item.ItemMultiPart:220" />. Это делается в <ItemLink id="appliedenergistics2:tile.BlockCellWorkbench" />.

Ячейки также поддерживают ограничения, позволяющие уменьшить как максимальную ёмкость в байтах, так и количество типов ниже их стандартных значений.

Это настраивается в элементе <ItemLink id="appliedenergistics2:tile.BlockCellWorkbench" />.

Предметы можно перетаскивать в слоты из NEI, даже если у вас на самом деле нет ни одного предмета.

## Улучшения

Ячейки хранения поддерживают следующие улучшения, которые добавляются в <ItemLink id="appliedenergistics2:tile.BlockCellWorkbench" />:

*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:29" /> (недоступно для ячеек с жидкостью) позволяет разделять по уровню повреждения и/или игнорировать NBT-атрибуты предмета
*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:31" /> переключает фильтр с белого списка на чёрный
*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:69" /> выделяет одинаковое количество байтов ячейки для каждого типа, чтобы один тип не мог заполнить всю ячейку
*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:68" /> удаляет новые предметы, если ячейка заполнена (или если выделенное пространство для данного конкретного типа закончилось при использовании карты с равным распределением), что полезно для предотвращения переполнения ферм. Будьте осторожны при разбиении на разделы!
*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:55" /> позволяет фильтровать с помощью словаря руд и поддерживает сопоставление по регулярным выражениям(regexp)
*   <ItemLink id="appliedenergistics2:item.ItemMultiMaterial:64" /> (работает только при когда ячейка разбита на разделы) указывает предпочтительное место хранения для определённых предметов или жидкостей. Отмеченные предметы и жидкости будут храниться только в ячейках, содержащих липкую карту, а не в других доступных местах для хранения в сети

# Storage Components

Storage Components are the core of ME Storage Cells and determine their storage capacity.

Each tier increases storage capacity by a factor of four and requires four components of the previous tier to craft. They can also be manufactured directly in a Circuit Assembler.

# Жидкостные компоненты хранения

Жидкостные компоненты хранения являются основой ME жидкостных ячеек хранения и определяют их ёмкость.

Каждый тир увеличивает ёмкость в четыре раза, а для его изготовления требуется четыре компонента предыдущего тира. Их также можно создать в сборщике электросхем.

# Жидкостные ячейки хранения

Стандартные жидкостные ячейки хранения делятся на две категории:

Жидкостные ячейки хранения могут хранить только один тип жидкости.

Мульти-жидкостные ячейки хранения жидкостей могут хранить до пяти типов жидкостей.

Обе категории доступны во всех стандартных тирах емкости.

# Компоненты хранения эссенции

Компоненты хранения эссенции это основа ME ячеек хранения эссенции и определяют их ёмкость.

Каждый тир увеличивает ёмкость в четыре раза, а для его изготовления требуется четыре компонента предыдущего тира. Их также можно создавать в сборщике электросхем.

# Ячейки хранения эссенции

Ячейки хранения эссенции емкостью от 1k до 64k поддерживают 12 типов эссенции.

Начиная с 256k, каждый тир увеличивает количество поддерживаемых типов эссенции на 12.
